# Glossary

- **Published skill**: a skill listed in an upstream collection's publication manifest.
- **Adapted skill**: an imported skill with maintained changes to upstream content.
- **Managed collection**: skill files owned by a specific sync process.
- **Source manifest**: `sources.json`, which records upstream locations, comparison revisions, selections, and update modes.
- **Package lockfile**: npm's record of the copying tool and its dependency versions.
