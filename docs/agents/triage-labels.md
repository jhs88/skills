| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |

These are the default canonical labels expected by the copied triage skill. No remote labels were created. Ask before provisioning missing labels or applying triage state on GitHub.
