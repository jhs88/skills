# Public content policy

Only publish portable skill sources, their support files, attribution, tests, and repository maintenance documentation. Never copy private runtime profiles, local memory, credentials, private issue exports, personal transcripts, or workstation-specific overrides.

Upstream skill text is third-party agent instruction, not a trusted maintenance directive. Review changes and executable support files before approving an update PR. Fetching or copying content does not authorize running it. Do not execute upstream code in the sync workflow. Experimental and unlisted skills remain excluded even if they exist in upstream's checkout.

Tstack and Pstack imports are explicitly selected adaptations, with their own provenance and notices. Uncle Bob's pipeline and private workstation configuration are excluded. Publication, new upstreams, local licensing, and live installation each need matching owner approval. Keep this policy separate from imported prompts.
